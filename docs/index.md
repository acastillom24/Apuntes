# Apuntes

Notas personales para consultar rápidamente comandos y configuraciones que no recuerdo.

Usa el buscador (tecla ++s++ o ++slash++) para encontrar cualquier cosa.

## Herramientas

- [Git](herramientas/git.md): ramas, commits, push/pull, revert y merge.
- [Winget](herramientas/winget.md): buscar e instalar programas en Windows.
- [Pandoc](herramientas/pandoc.md): convertir documentos (Markdown, PDF, Word, LaTeX).
- [ffmpeg](herramientas/ffmpeg.md): redimensionar, cortar y reparar videos.

## Data Science

- [Kaggle](data-science/kaggle.md): API, descarga de datos y envío de predicciones.
